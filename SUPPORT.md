# Support

This repository is a **community lab guide** for F5 Workforce AI Security (WAIS) on
UDF. It is maintained on a best-effort basis.

> **This is not a production support channel.** It does not provide official F5
> product support for WAIS, the UDF Blueprint, or the tenant provisioning service.
> For product support, use your organization's normal F5 support path.

## How to get help with the lab guide

- **Documentation problems** (a wrong step, broken link, missing/incorrect
  screenshot, confusing wording): open a **Documentation bug** issue using the
  [template](.github/ISSUE_TEMPLATE/documentation-bug.md).
- **Lab/environment problems** (a module behaves differently than documented, the
  tenant or client does not reach the expected state): open a **Lab issue** using the
  [template](.github/ISSUE_TEMPLATE/lab-issue.md). Include the module, the deployment
  state, and **sanitized** logs only.

## Please do not include secrets

When filing an issue or attaching a screenshot, **remove** tenant passwords,
usernames, connector IDs, PAC URLs, tokens, internal IP addresses, and any personal
data. Redact screenshots before uploading.

## Before filing

- Check the guide's **Troubleshooting the Tenant Instance** appendix.
- Confirm you are using the supported **Windows 11 lab client**.
- Confirm your Blueprint is deployed and the tenant-ready page is reachable.
